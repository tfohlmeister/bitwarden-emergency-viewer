Bitwarden Emergency Viewer

One HTML file that opens a password-protected Bitwarden or Vaultwarden export with nothing but a browser. No server, no account, no network.

Try it

  1. Download the demo export.
  2. Open the viewer.
  3. Choose the file you just downloaded and enter the master password demo.

The demo vault holds invented entries only. It uses Bitwarden's own Argon2id defaults, so unlocking takes a few seconds; that is the key derivation doing its job.

Why the file picker and not a link

The viewer declares default-src 'none' and loads nothing at all, so it cannot fetch the export for you even here. That restriction is the point: a page that cannot reach the network cannot leak a decrypted vault. The file reaches it through the picker, which needs no permission and no connection.

In an emergency

Save viewer.html next to your export in the same backup. This page exists to demonstrate the tool, not to be a dependency: if you have to visit a website to read your passwords, the tool has already failed.
